SimplyDB
========

First use:
----------
When the app is started for the first time, 4 .dat files are created in the My Computer directory.
The files must remain in this location.
Since the files are empty you can start filling them in the app. Or you can copy the already existing files in the App directory to the My Computer directory for testing. The test files are already filled and you can get a first overview.
As soon as you delete the files in the workspace again, the app automatically creates 4 new, empty files.

How to start:
--------------
When you have started the app, start by creating categories. To do this, simply click on "Add / edit category" in the MISC menu bar.
Here you can create categories for your records that you want to manage.
Under the menu item EDIT and NEW ENTRY you can then create and manage records for the respective categories.
With a click on MISC and Edit column headers you have the possibility to change the titles or headers for each category.

Under Options you can, among other things, set the color appearance of the forms and change the language. Please keep in mind that the program must be restarted after each change.
