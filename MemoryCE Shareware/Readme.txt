Building
--------

To rebuild the cab files run the following command

"C:\Programme\Microsoft eMbedded Tools\EVB\cabwiz.exe" "C:\Dokumente und Einstellungen\Administrator\Eigene Dateien\Windows CE\MemoryCE Shareware\MemoryCE.INF" /cpu "Mips 4000 (1K) v2.10" "SH 4 (4K) v2.10" "Arm 1100 (4K) v2.10" "SH 3 (1K) v2.10"

Then copy the CAB files created to the CD1 directory.


File List
---------

Everything in the CD1 directory is required to install your application.
